## レッスン本文
第1次ブームの探索・推論と、第2次ブームの知識表現・エキスパートシステムを押さえます。
### 探索・推論（第1次AIブーム）
迷路やハノイの塔のような問題を、場合分けを尽くして解く探索・推論が中心でした。手前から順に探す幅優先探索と、行けるところまで進む深さ優先探索、ゲームの手を読むMini-Max法と無駄な枝を刈るαβ法、ランダムな試行を重ねるモンテカルロ法が代表格です。
### トイプロブレムの壁
当時扱えたのは、現実の複雑さを削ぎ落とした簡略な問題（トイプロブレム）に限られました。現実世界の問題は解けないと分かり、第1次ブームは冬の時代を迎えます。
### 知識表現（第2次AIブーム）
専門家の知識をルールとして詰め込むエキスパートシステムが登場し、感染症診断のMYCINが有名です。知識の表し方として意味ネットワークやオントロジー、一般常識を大量に記述するCycプロジェクトも進みました。しかし知識を人手で書き出す作業が膨大で、知識獲得のボトルネックが壁となり再び冬の時代に入ります。

## 既存の確認問題（重複禁止・確認問題の難易度の手本）
- [幅優先探索] 探索木を用いた問題解決における『幅優先探索』の特徴として最も適切なものはどれか。 → 起点に近い浅いノードから順にすべて調べ、最短手順を見つけやすいがメモリを多く必要とする
- [深さ優先探索] 『深さ優先探索』の特徴として最も適切なものはどれか。 → 一つの経路を行き止まりまで掘り下げ、行き詰まると後戻りして別の経路を試す探索
- [ハノイの塔] 探索アルゴリズムを学ぶ際の例題として古くから用いられる『ハノイの塔』の説明として最も適切なものはどれか。 → 小さい円盤の上に大きい円盤を置かないよう、円盤を別の杭へ移し替えるパズルの問題
- [モンテカルロ法] 囲碁AIなどで用いられる『モンテカルロ法(モンテカルロ木探索)』の考え方として最も適切なものはどれか。 → 終局までランダムな試行を多数繰り返し、勝率の統計から手を評価する方法
- [Mini-Max法] 二人零和有限確定完全情報ゲームなどで用いられる『Mini-Max法』の考え方として最も適切なものはどれか。 → 自分の手番では評価値を最大にする手を、相手は自分の評価値を最小にする手を選ぶと仮定して探索する
- [αβ枝刈り] Mini-Max法による探索を効率化する『αβ枝刈り』の説明として最も適切なものはどれか。 → 最終的な評価を変えずに、選ばれないと分かった枝の探索を早めに打ち切って計算量を減らす
- [意味ネットワーク] 知識表現の手法の一つである『意味ネットワーク』の説明として最も適切なものはどれか。 → 概念をノード、上位下位などの概念間の関係をリンクとして表現する知識表現の方法
- [オントロジー] AI分野における『オントロジー』の説明として最も適切なものはどれか。 → 概念と関係を体系化し、知識の共有・再利用を容易にする枠組み
- [Cycプロジェクト] 1984年に開始された、人間が持つ膨大な常識をコンピュータに与えることを目指した長期プロジェクト『Cyc』を主導した人物は誰か。 → ダグラス・レナート
- [マイシン(MYCIN)] 1970年代にスタンフォード大学で開発された、血液感染症の診断支援を行うエキスパートシステム『マイシン(MYCIN)』の説明として最も適切なものはどれか。 → 医師の知識をルール化して蓄積し、症状から感染症の病名や処方薬を推論するシステム
- [知識獲得のボトルネック] エキスパートシステムの開発・運用における『知識獲得のボトルネック』が指す問題として最も適切なものはどれか。 → 専門家の暗黙の知識をルールとして引き出し整理する作業に、多大な労力を要してしまう問題
- [幅優先探索/深さ優先探索] 将棋の合法手をすべて調べ上げて必勝手順を確実に見つけたいが、扱うコンピュータのメモリ容量が極めて限られているとする。このとき、幅優先探索と深さ優先探索のどちらを選ぶべきかについての説明として、最も適切なものはどれか。 → 深さ優先探索は保持するノード数を抑えやすく、メモリ制約下では適している
- [モンテカルロ木探索とMini-Max法の使い分け] チェスや将棋のAIでは長らくMini-Max法とαβ枝刈りを用いた探索が主流であったのに対し、囲碁AIの多くがモンテカルロ木探索を採用してきた背景として、最も適切な説明はどれか。 → 囲碁は分岐数が多く精緻な評価関数を作りにくく、勝率統計での評価が有効だから
- [第1次・第2次AIブームの技術比較] 第1次AIブームにおける『推論・探索』を中心とした研究と、第2次AIブームにおける『知識表現・エキスパートシステム』を中心とした研究の違いを説明したものとして、最も適切なものはどれか。 → 第1次はトイプロブレムが対象、第2次は専門知識で現実の問題を扱った
- [Cycプロジェクトと知識獲得のボトルネック] ダグラス・レナートが主導したCycプロジェクトは、大量の常識的知識をルールとして人手で入力し続けることで人工知能に常識推論をさせることを目指した。このプロジェクトの手法自体が直面した根本的な課題を説明したものとして、最も適切なものはどれか。 → 常識を人手でルール化し続ける作業に膨大な労力がかかり続けたこと
