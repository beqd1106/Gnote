## レッスン本文
企画から運用までの流れ、体制の考え方、運用後の劣化への対応を押さえます。
### 進め方の全体像
目的設定→データ収集→モデル構築→評価→運用のサイクルで進めます。データ分析の標準的な進め方の枠組みがCRISP-DM、小さく作って実現性を確かめる工程がPoC（概念実証）です。AIは事前に性能を確約できないため、段階を踏んで進めることが重要になります。業務のやり方そのものを見直すBPRや、企画を1枚に整理するAIキャンバスも活用されます。
### 体制と内製・外注
自社で人材を育てて内製するか、外部に委託するかは、データやモデルの権利の所在、ノウハウの蓄積、スピードを踏まえて判断します。委託する場合は契約で権利と責任の分担を明確にします。
### 運用とモデルの劣化
開発環境と本番環境の差を吸収するにはコンテナ（Docker）が使われます。運用を継続的に回す仕組みがMLOpsです。時間の経過とともに現実のデータ傾向が学習時から変化し精度が落ちる概念ドリフトが起きるため、監視と再学習の計画が欠かせません。

- b-imp1-04 [PoC] AIプロジェクトでしばしば課題となる「PoC止まり（PoC死）」とはどのような状態か。 → 小規模な検証ばかりが繰り返され、本番導入に進まない状態
- b-imp1-05 [内製・外注] AI開発を外部に委託する際、契約であらかじめ明確にしておくべきこととして最も適切なものはどれか。 → 開発したデータやモデルに関する権利と責任の分担
- b-imp1-06 [内製・外注] AI開発における「内製」と「外注」の一般的な違いとして最も適切なものはどれか。 → 内製はノウハウ蓄積に強く、外注は専門性やスピードに強い
- b-imp1-07 [MLOps] 「MLOps」という用語がもとになっている英語表現として正しいものはどれか。 → Machine Learning Operations
- b-imp1-08 [内製・外注] AI開発の体制を検討する際、データやモデルの「権利の所在」を確認しておく理由として最も適切なものはどれか。 → 後の利用や第三者提供の範囲が、権利の主体によって変わるため
- b-imp1-09 [AIプロジェクトの進め方] AIプロジェクトにおける目的設定から運用までの一連の流れが持つ性質として最も適切なものはどれか。 → 運用後も評価や再学習を重ね、継続的に回していくサイクルである

## 既存の確認問題（重複禁止・確認問題の難易度の手本）
- [AIプロジェクトの進め方] AIプロジェクトを始める際、最初に行うべきこととして最も適切なものはどれか。 → ビジネス課題を整理し、AIで解く目的と達成すべきゴールをはっきりさせる
- [PoC] PoC（Proof of Concept）についての説明として最も適切なものはどれか。 → AIが課題の解決に有効かを小規模に試して確かめる概念実証の段階
- [CRISP-DM] データ分析プロジェクトの標準的な進め方を示す方法論であるCRISP-DMにおいて、一般的に最初に位置づけられる工程はどれか。 → 課題と目的を明確にするビジネス理解（Business Understanding）
- [MLOps] MLOps（Machine Learning Operations）が目指すものとして最も適切な説明はどれか。 → 開発から本番の運用・監視までを一貫して自動化する取り組み
- [内製・外注] AI開発を内製するか外注するかを検討する際の考え方として、最も適切なものはどれか。 → 社内のAI人材やデータの蓄積を見て、ノウハウの必要性やコストや速度も踏まえ判断する
- [ビジネスバリュー] PoC（概念実証）において機械学習モデルが目標精度を達成した。この結果を踏まえて本導入の可否をビジネス側で判断する際、精度の数値以外に確認すべき最も重要な観点はどれか。 → 見込まれる事業インパクトが開発・運用にかかる投資に見合うかどうか
- [AIの品質保証・運用監視] 本番運用中のAIモデルの品質保証・モニタリングの取り組みとして最も適切なものはどれか。 → 本番投入後の予測精度や入力データの分布を継続的に監視し、劣化を早期に見つける
- [プライバシー・バイ・デザイン] AIを用いたサービスの企画・設計段階からプライバシー保護の仕組みをあらかじめ組み込んでおくという考え方を表す用語として最も適切なものはどれか。 → プライバシー・バイ・デザイン
- [モデルの再学習] 運用中のモデルについて、入力データの傾向が変化する概念ドリフトが疑われる兆候をモニタリングで捉えた。この状況への対応として最も適切なものはどれか。 → 監視指標を確認し、最新のデータで再学習して検証してから置き換える
- [開発と運用] AIモデルを動かすアプリケーションを、必要なライブラリや設定ごとひとまとめにし、どの環境でも同じように動作させる目的で使われる技術はどれ？ → コンテナ（Dockerなど）
- [AIプロジェクトの進め方] 既存の業務プロセスの前提そのものを見直し、AI導入に合わせて業務フローを抜本的に再設計する取り組みを表す言葉はどれ？ → 業務の前提を見直すBPR（ビジネスプロセス・リエンジニアリング）
- [開発と運用] 運用開始から1年が経過したところ、学習時と比べて実世界のデータの傾向が変化し、モデルの予測精度が徐々に低下してきた。この現象を指す言葉として最も適切なものはどれ？ → 概念ドリフト
- [AIプロジェクトの進め方] 「AIキャンバス」の説明として最も適切なものはどれ？ → 目的・データ・関係者・リスクを1枚に整理し全体を見渡す枠組み
