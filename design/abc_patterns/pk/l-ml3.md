## レッスン本文
過学習と汎化性能、混同行列から導く評価指標、正則化までを押さえます。
### 過学習と汎化
訓練データに合わせすぎて未知データで精度が落ちるのが過学習、そもそも学習不足なのが未学習です。汎化性能を測るためデータを訓練・検証・テストに分け、1回だけ分割するホールドアウト法や、分割を変えて繰り返すk分割交差検証を使います。
### 分類の評価指標
予測と正解の組み合わせを整理した混同行列から各指標を計算します。適合率＝TP/(TP+FP)は『陽性と予測したうちの正解率』、再現率＝TP/(TP+FN)は『実際の陽性を取りこぼさない率』で、両者は трейドオフの関係にあり調和平均のF値で総合評価します。閾値を動かして描くROC曲線の下面積がAUCです。
### バイアス・バリアンスと正則化
モデルが単純すぎる誤差（バイアス）と、データの揺らぎに敏感すぎる誤差（バリアンス）はトレードオフの関係にあります。過学習を抑えるには、重みの大きさに罰則を課す正則化（不要な特徴量の係数を0にしやすいL1＝ラッソ、全体を滑らかに抑えるL2＝リッジ）が有効です。

## 既存の確認問題（重複禁止・確認問題の難易度の手本）
- [過学習（オーバーフィッティング）] 機械学習モデルにおける「過学習（オーバーフィッティング）」の説明として、最も適切なものはどれか。 → 訓練データのノイズまで学習し、未知データへの汎化精度が低下した状態である
- [未学習（アンダーフィッティング）] 機械学習モデルにおける「未学習（アンダーフィッティング）」の説明として、最も適切なものはどれか。 → モデルの表現力や学習の不足で、訓練データに対しても十分な精度が出ない状態
- [正則化（L1/L2）] 線形回帰における正則化（L1正則化・L2正則化）に関する記述として、最も適切なものはどれか。 → パラメータの大きさに応じた罰則を損失に加え、過学習を抑える手法である
- [交差検証（k分割交差検証）] k分割交差検証（k-fold cross validation）に関する記述として、最も適切なものはどれか。 → データをk分割し、検証用を入れ替えながらk回学習・評価して結果を平均する手法
- [混同行列] 分類問題における混同行列（confusion matrix）に関する記述として、最も適切なものはどれか。 → 実際のクラスと予測クラスの組み合わせごとに、件数を集計した表である
- [適合率・再現率] 分類モデルの評価指標である適合率（Precision）と再現率（Recall）に関する記述として、最も適切なものはどれか。 → 適合率は正と予測したうち実際に正の割合、再現率は実際の正を捉えた割合
- [F値（F1スコア）] 適合率（Precision）と再現率（Recall）の両方をバランスよく評価するための指標であるF値（F1スコア）に関する記述として、最も適切なものはどれか。 → 適合率と再現率の調和平均で、両者が共に高いときに高くなる指標である
- [ROC曲線・AUC] 2値分類モデルの評価に用いられるROC曲線とAUCに関する記述として、最も適切なものはどれか。 → 閾値を変えて偽陽性率と真陽性率を描くのがROC曲線、その下面積がAUC
- [バイアスとバリアンスのトレードオフ] モデルの汎化誤差を考える際の「バイアスとバリアンスのトレードオフ」に関する記述として、最も適切なものはどれか。 → 表現力を上げるとバイアスは減るがバリアンスは増えやすく、両立が難しくなるという関係
- [適合率・再現率・F値の計算] ある2値分類モデルをテストデータ100件に適用したところ、混同行列は次の通りであった：真陽性(TP)=40件、偽陽性(FP)=10件、偽陰性(FN)=20件、真陰性(TN)=30件。このときの適合率（Precision）、再現率（Recall）、F値（F1スコア）の組み合わせとして、最も適切なものはどれか（小数第3位を四捨五入）。 → 適合率0.80、再現率0.67、F値0.73
- [不均衡データにおける正解率の落とし穴] 不正利用検知のように、正例（不正）が全体のごく一部（1000件中20件）しか存在しない不均衡データに対して、「常に負例（正常）と予測する」単純なモデルを適用した場合の評価に関する記述として、最も適切なものはどれか。 → 正解率は0.98と高いが再現率は0で、正解率だけで見ると性能を過大評価する
- [データリーケージ] 機械学習モデルの構築プロセスにおける「データリーケージ（data leakage）」の説明として、最も適切なものはどれか。 → 予測時に使えない情報が訓練に混入し、評価が運用時より過大に良く見える問題
- [L1正則化とL2正則化の違い] 線形回帰におけるL1正則化（Lasso）とL2正則化（Ridge）の違いに関する記述として、最も適切なものはどれか。 → L1は係数を0にしやすく特徴選択の効果を持ち、L2は0に近づけるが0にはしにくい
- [ホールドアウト法とk分割交差検証の使い分け] モデル評価手法であるホールドアウト法とk分割交差検証の使い分けに関する記述として、最も適切なものはどれか。 → データが豊富ならホールドアウト法で安定、少なければk分割交差検証が有効である
- [モデルの評価] 「次元の呪い」に関する説明として、最も適切なものはどれか。 → 次元が増えるほど空間がスカスカになり、必要なデータ量が急増する現象
