## レッスン本文
画像認識モデルの系譜、物体検出、セグメンテーション・姿勢推定を押さえます。
### 画像認識モデルの系譜
2012年のILSVRCでAlexNetが圧勝して以降、層を深くしたVGG、複数サイズのフィルタを並列に使うGoogLeNet（Inception）、スキップ結合で超深層を可能にしたResNet、深さ・幅・解像度をバランスよく拡大したEfficientNetへと発展しました。近年は画像をパッチに分割しTransformerで扱うVision Transformerも主流です。
### 物体検出
画像中の物体の位置（バウンディングボックス）と種類を求めるタスクです。候補領域の提案と分類を分ける2段階検出（R-CNN→Fast R-CNN→Faster R-CNNと高速化）と、1回の処理でまとめて行う1段階検出（YOLO、SSD）に大別され、後者は高速です。
### セグメンテーションと姿勢推定
ピクセル単位で領域を塗り分けるのがセマンティックセグメンテーション（FCN、U-Net、SegNet）で、同じクラスでも個体を区別するのがインスタンスセグメンテーション（Mask R-CNN）です。人物の関節点を検出して姿勢を推定するOpenPoseも代表的な応用です。

## 既存の確認問題（重複禁止・確認問題の難易度の手本）
- [AlexNet] 2012年のILSVRC(ImageNetの画像認識コンペティション)で圧倒的な性能で優勝し、ディープラーニングブームのきっかけとなったモデルはどれか。 → AlexNet
- [VGGNet] 画像認識モデルVGGNetの特徴として最も適切なものはどれか。 → 3×3の小さな畳み込みフィルタを多数積み重ねることでネットワークを深くした
- [GoogLeNet(Inception)] GoogLeNet(Inception)が導入した工夫として正しいものはどれか。 → サイズの異なる畳み込みとプーリングを並列に組み合わせて特徴を捉えるInceptionモジュールを導入した
- [ResNet] ResNet(Residual Network)が非常に深いネットワークの学習を可能にした中心的な仕組みはどれか。 → 入力をそのまま後段の出力に加算する残差接続を導入し勾配消失を緩和した
- [EfficientNet] EfficientNetが提案した、モデルの精度と効率を両立させるための手法はどれか。 → 深さ・幅・解像度を一定比率で同時に拡大し効率を高める複合スケーリング
- [R-CNN] 物体検出手法R-CNNの処理の流れとして正しいものはどれか。 → Selective Searchで候補領域を多数抽出しCNNで特徴を得た後SVMで分類する
- [Fast R-CNN] Fast R-CNNがR-CNNから改良した点として正しいものはどれか。 → RoIプーリングを導入し、画像全体を1度だけCNNに通して特徴マップを共有することで高速化した
- [Faster R-CNN] Faster R-CNNの特徴として正しいものはどれか。 → 候補領域をCNNから直接生成するRPNを導入しFast R-CNNと統合した
- [YOLO] 物体検出手法YOLO(You Only Look Once)の最大の特徴として正しいものはどれか。 → 画像を1度CNNに通すだけで、物体の位置とクラスを同時に予測し、リアルタイムに高速検出できる
- [SSD] 物体検出手法SSD(Single Shot MultiBox Detector)の特徴として適切なものはどれか。 → ネットワーク内の複数解像度の特徴マップを使い、1回の順伝播で様々な大きさの物体を検出する
- [FCN] セマンティックセグメンテーションで用いられるFCN(Fully Convolutional Network)の特徴として正しいものはどれか。 → 全結合層を畳み込み層に置き換え、任意サイズの画像で画素単位の分類を出力する
- [U-Net] 医療画像などのセグメンテーションで広く使われるU-Netの構造上の特徴として正しいものはどれか。 → エンコーダとデコーダをU字型に結び、対応層をスキップ接続でつなぐ構造
- [IoU(Intersection over Union)] 物体検出における評価指標IoU(Intersection over Union)の説明として正しいものはどれか。 → 予測と正解のボックスの重なりを、両者の和集合の面積で割った値
- [NMS(Non-Maximum Suppression)] 物体検出において、同一の物体に対して重なり合う複数のバウンディングボックスが検出された際に、IoUなどを基準にして最もスコアの高いボックスだけを残し、他の重複したボックスを除去する後処理はどれか。 → 非最大抑制(Non-Maximum Suppression)
- [1段階検出と2段階検出] Faster R-CNNのような2段階(Two-stage)検出方式と、YOLOやSSDのような1段階(One-stage)検出方式の一般的な傾向の比較として最も適切なものはどれか。 → 1段階方式は候補領域の提案を行わず直接予測するため高速だが、小物体の検出で劣る傾向
