## レッスン本文
Attentionの仕組みとTransformer、オートエンコーダ・データ拡張・転移学習を押さえます。
### Attentionの仕組み
入力のどこに注目すべきかを重み付けして学ぶのがAttentionです。QueryとKeyの内積で関連度を測りValueを取り出す仕組みで、同一系列内の要素同士の関連を見るものをSelf-Attention（自己注意）と呼びます。離れた位置にある単語同士の関係も直接捉えられるのが強みです。
### Transformer
再帰も畳み込みも使わず、Self-Attentionだけで系列を処理するのがTransformerです。並列計算しやすく大規模化に向き、BERTやGPTの基盤となりました。複数の視点で同時に注意を計算するMulti-Head Attentionと、語順の情報を与える位置エンコーディングが要素技術です。
### オートエンコーダ・データ拡張・転移学習
入力を圧縮して復元するオートエンコーダは特徴表現の学習や異常検知に使え、潜在変数を確率分布として学ぶVAEは生成にも使えます。学習データを回転・反転・Cutout・Mixupなどで水増しするデータ拡張は過学習対策として有効です。学習済みモデルを別タスクに流用するのが転移学習、その重みを再調整するのがファインチューニング。蒸留・量子化・プルーニングはモデルを軽量化する手法です。

## 既存の確認問題（重複禁止・確認問題の難易度の手本）
- [Attention] ニューラルネットワークにおける「Attention(注意機構)」の基本的な考え方として、最も適切なものはどれか。 → 入力の各要素の重要度を重みとして計算し、その重み付き和で出力に反映する仕組み
- [Self-Attention] Self-Attention(自己注意)の計算に関する記述として、最も適切なものはどれか。 → 同一系列からQuery・Key・Valueを作り、QとKの内積の重みでVを加重平均する
- [Transformer] Transformerの基本構造に関する記述として、最も適切なものはどれか。 → 再帰も畳み込みも使わず、Attention中心の層を積み重ねる
- [マルチヘッドアテンション] Transformerにおける「マルチヘッドアテンション」の目的として、最も適切なものはどれか。 → 複数の部分空間で並列にAttentionを計算し、異なる観点の関係を捉える
- [位置エンコーディング] Transformerにおける「位置エンコーディング(Positional Encoding)」が必要とされる理由として、最も適切なものはどれか。 → Self-Attentionは並び順を区別できないため、位置情報を別途埋め込んで与える
- [オートエンコーダ] オートエンコーダ(Autoencoder)の基本構造に関する記述として、最も適切なものはどれか。 → 入力を潜在表現へ圧縮するエンコーダと元へ復元するデコーダから成り、教師なしで学習する
- [オートエンコーダ] オートエンコーダが次元圧縮や特徴抽出に利用される理由として、最も適切なものはどれか。 → 中間層を入力より小さくし、本質的な特徴を圧縮して表現するよう学習する
- [VAE] VAE(変分オートエンコーダ)が通常のオートエンコーダと異なる点として、最も適切なものはどれか。 → 潜在変数を単一のベクトルでなく確率分布で表し、そこからサンプリングする
- [VAE] VAEの損失関数を構成する主な2つの項として、最も適切な組み合わせはどれか。 → 入力と出力の近さを表す再構成誤差と、事前分布に近づけるKL項の2つ
- [データ拡張] 画像データに対する「データ拡張(Data Augmentation)」を行う主な目的として、最も適切なものはどれか。 → 反転や回転を加えた画像を追加して多様性を増やし、過学習を抑えて汎化性能を高める
- [データ拡張] 画像データに対するデータ拡張の具体的な手法として、一般的に用いられないものはどれか。 → 学習データの正解ラベルを、すべてランダムな値に置き換える操作
- [Transformer(スケーリング)] Transformerのスケール化内積注意(Scaled Dot-Product Attention)において、QueryとKeyの内積をd_k(Keyベクトルの次元数)の平方根で割る理由として、最も適切なものはどれか。 → 次元が大きいと内積が過大になりsoftmaxの勾配が小さくなるのを防ぐため
- [マルチヘッドアテンション(次元計算)] Transformerのマルチヘッドアテンションで、モデル全体の次元数(d_model)が512、ヘッド数が8のとき、各ヘッドで扱われるQuery・Keyベクトルの次元数(d_k)として、一般的に用いられる値はどれか。 → 64
- [VAE(再パラメータ化トリック)] VAE(変分オートエンコーダ)で用いられる「再パラメータ化トリック(reparameterization trick)」の目的として、最も適切なものはどれか。 → サンプリングをμ+σ⊙εで表し、確率的な計算でも逆伝播を可能にする
- [データ拡張(Cutout)・正則化(Dropout)] 画像データに対するCutoutと、全結合層などで用いられるDropoutの違いに関する記述として、最も適切なものはどれか。 → Cutoutは画像の矩形領域を遮蔽し、Dropoutは全結合層のユニットを無効化する
